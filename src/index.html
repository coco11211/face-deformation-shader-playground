About Face Deformation Studio

Version 1.0.0

A production-ready application for real-time face deformation effects using WebGL shaders.

Features:

  • 10 unique shader effects
  • Real-time face detection and tracking
  • Customizable effect parameters
  • Frame export functionality
  • Optimized for Windows 11

Technologies:

  • Electron
  • Three.js (WebGL)
  • TensorFlow.js
  • MediaPipe Face Mesh
